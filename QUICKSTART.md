# ⚡ Быстрый старт Úmit Platform

## 🚀 Запуск за 3 минуты

### Шаг 1: Клонируйте репозиторий
```bash
git clone https://github.com/timon777/.github.io.git
cd .github.io
git checkout claude/umit-social-platform-mvp-011CUVoaAtefuyRBjKvCYRFo
```

### Шаг 2: Установите зависимости
```bash
npm install
```

### Шаг 3: Запустите dev-сервер
```bash
npm run dev
```

Откройте http://localhost:3000 в браузере! 🎉

## 🐛 Устранение неполадок

### Ошибка при установке зависимостей
```bash
rm -rf node_modules package-lock.json
npm install
```

### Порт 3000 занят
Измените порт в `vite.config.ts`:
```typescript
server: {
  port: 3001, // Измените на свободный порт
}
```

### TypeScript ошибки
Проект настроен на work without strict mode. Если видите TS ошибки, они не критичны.

## 📦 Следующие шаги

### 1. Настройка Supabase бэкенда

Создайте `.env`:
```bash
cp .env.example .env
```

Отредактируйте:
```env
VITE_DIRECTUS_URL=http://your-supabase-server:8055
```

### 2. Создайте коллекции в Supabase

Необходимые коллекции:
- `users` (расширить стандартную)
- `help_requests`
- `responses`
- `shelters`
- `locations`
- `achievements`
- `emergencies`

Схемы см. в `src/types/index.ts`

### 3. Замените mock данные

В следующих файлах замените моки на API вызовы:
- `src/pages/RequestsPage.tsx`
- `src/pages/SheltersPage.tsx`
- `src/pages/VolunteersPage.tsx`
- `src/pages/ProfilePage.tsx`
- `src/pages/MapPage.tsx`

### 4. Добавьте функционал

- Push-уведомления
- Чат между пользователями
