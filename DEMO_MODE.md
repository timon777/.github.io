# 🔶 DEMO MODE - Работа без Supabase

## Что это?

**Demo Mode** позволяет запустить и протестировать фронтенд приложения **без настройки Supabase**.
Все данные используются из локальных mock-файлов.

## Когда активируется Demo Mode?

Автоматически, если в `.env` файле **НЕ** заполнены:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## Как работает?

При запуске вы увидите в консоли браузера:
```
🔶 DEMO MODE: Supabase не настроен. Используются mock данные.
📝 Для подключения к БД настройте .env файл (см. SUPABASE_SETUP.md)
```

### Что работает в Demo Mode:

✅ **Просмотр интерфейса** - все страницы отображаются
✅ **Навигация** - переходы между страницами
✅ **Вход/Регистрация** - эмуляция через localStorage
✅ **Просмотр данных** - показываются mock запросы, приюты, волонтёры
✅ **Формы** - можно заполнять (данные логируются в консоль)
✅ **Фильтры** - работают на mock данных

### Что НЕ сохраняется:

❌ Новые запросы/приюты не сохраняются в БД
❌ Загрузка изображений эмулируется placeholder'ами
❌ Изменения теряются при перезагрузке (кроме auth в localStorage)

## Демо данные

Находятся в `src/services/mockData.ts`:

- **2 пользователя** (1 волонтёр, 1 нуждающийся)
- **2 запроса помощи** (продукты, одежда)
- **2 приюта** (для животных, для людей)
- **3 топ-волонтёра** с рейтингом

## Демо вход

При входе в систему в demo режиме:

- **Email**: любой (например: `demo@umit.asia`)
- **Пароль**: любой (например: `123456`)

Система автоматически авторизует вас как демо-пользователя.

## Как перейти на реальную БД?

1. Создайте проект на [supabase.com](https://supabase.com)
2. Выполните SQL из `supabase-schema.sql`
3. Заполните `.env` файл:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key-here
   ```
4. Пересоберите проект: `npm run build`

Подробнее см. [SUPABASE_SETUP.md](./SUPABASE_SETUP.md)

## Для разработчиков

### Добавление mock данных

Редактируйте `src/services/mockData.ts`:

```typescript
export const mockHelpRequests = [
  {
    id: 'request-1',
    title: 'Нужна помощь',
    category: 'food',
    // ...
  },
]
```

### Проверка режима в коде

```typescript
import { isDemoMode } from './services/supabase'

if (isDemoMode) {
  console.log('Работаем в demo режиме')
}
```
